# MandirVastu

MandirVastu is a web-based encyclopedia that documents the architectural, iconographic and symbolic elements of Indian temples.

Developed as part of an Indian Knowledge Systems (IKS) project, MandirVastu presents temple architecture, symbolism and traditional design principles through a structured digital platform.

## Project Snapshot

- 48 Temple Elements
- 3 Architectural Traditions
- Responsive Design
- Live Deployment

## Highlights

- Covers 48 temple elements and 3 major architectural traditions
- Responsive design across desktop, tablet and mobile devices
- Interactive visual elements and image-based content
- Optimized for different screen sizes and pixel densities
- Performance-conscious design for smoother experience on low-end devices
- Search-engine optimized structure with metadata, sitemap and robots configuration

## Technologies Used

* HTML
* CSS
* JavaScript

## Live Website

https://mandirvastu.online

## Project Context

This project was developed as part of an Indian Knowledge Systems (IKS) initiative to digitally document and present knowledge related to Indian temple architecture and iconography in an organized and user-friendly format.
